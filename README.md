## 📝 Descrição do Projeto

O **Simulado-Saep** é um sistema web profissional desenvolvido para o gerenciamento e controle de estoque de vestuário. Projetado especificamente como uma solução para o simulado da prova SAEP, o sistema foca na usabilidade, persistência de dados e eficiência operacional para lojas e comércios de roupas.

A aplicação resolve problemas comuns de logística têxtil, garantindo um fluxo correto desde a entrada da mercadoria até a sua movimentação final.

---

## 🚀 Principais Funcionalidades

*   📦 **Cadastro de Produtos (Roupas):** Registro completo de peças com especificações de categoria, tamanho, cor e valores.
*   🔄 **Movimentação de Estoque:** Controle rigoroso de entradas e saídas de mercadorias, evitando furos no inventário e garantindo dados atualizados em tempo real.
*   📊 **Consulta Rápida:** Interface intuitiva para filtragem e visualização do status atual do estoque.
*   🗄️ **Persistência de Dados:** Estrutura de banco de dados relacional (MySQL) otimizada para integridade das informações cadastrais.

---

## 🛠️ Tecnologias Utilizadas

O ecossistema do projeto foi construído utilizando tecnologias modernas e eficientes para o desenvolvimento web:

*   **HTML5 & CSS3:** Estruturação semântica e estilização responsiva da interface.
*   **JavaScript (ES6+):** Lógica de negócios no front-end e interatividade nas movimentações.
*   **MySQL:** Modelagem, armazenamento e gerenciamento seguro do banco de dados relacional.
*   **GitHub:** Controle de versão e versionamento profissional do código-fonte.
